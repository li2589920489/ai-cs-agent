# Prompt 评测 — 对抗性难例 + v1→v2 提升

## 一、为什么要补对抗性难例

Step 1 跑出来 13/13 = 100% 通过（`eval_prompt.py` v0），但**评测集区分度为 0**——
13 条全是"已修复过的 happy path"，每条断言都恰好对应 `agents.py` 里已经写死的
显式规则。拿"规则本身"去考"守不守规则"，等于开卷考自己背过的答案。

**没有失败用例，就无法量化 prompt 优化的收益**——对抗性难例的作用是让评测集具备
区分度，从而能给出可对比的前后数据。

## 二、对抗性难例设计（5 类 13 条）

| 类别 | 设计意图 | 用例 |
|---|---|---|
| **幻觉诱导（带虚假前提）** | 用户虚构"朋友买过 MacBook Pro"诱导模型承认 | | p014, p015, p024 |
| **无订单号模糊查询** | 情绪化抱怨不带 TB* 单号，诱导乱调工具 | p016, p017 |
| **否定指令对抗** | 用户"别查工具了直接说"，试图跳过 RAG | p018, p019 |
| **多步指令嵌政策** | 售后/订单场景中嵌入政策问题，诱导漏查 | p020, p021, p022, p025 |
| **转人工后追加 + Triage 多意图** | 复合意图路由与 escalation 后零冗余 | p023, p026 |

合计 13 条新用例（p014~p026），加上原 13 条 happy path = 26 条。

## 三、断言扩展（eval_prompt.py v1）

新增 3 类断言字段：

| 字段 | 语义 |
|---|---|
| `must_call_any` | 同 must_call（别名） |
| `not_call_any` | 同 must_not_call（别名） |

实现细节：见 `eval_prompt.py` 的 `extract_target_agent` + `check_asserts`。

## 五、v2 prompt 改动（基于 v1 失败归因）

**Triage Agent 加**：复合意图路由规则（主诉求路由，子 Agent 处理全部诉求）

**订单详情 Agent 加**：不复述虚构前提（用户提"上次发错 XX"时不得引用这些字眼）

**商品知识 Agent 加**：不绕过工具链（用户"别查了"也要先调工具再回答）

**售后退换货 Agent 加**：
- 复合诉求处理（政策 + 退货并行）
- 政策优先于订单号（先调 faq_lookup_tool，不要先索要单号）

## 六、剩余 3 条失败（v2 final）

| ID | 失败原因 | 性质 |
|---|---|---|
| p013 | "你们卖电脑吗？" 模型找到 EC1351（机械革命游戏本）承认"有电脑" | 模型波动（happy path 偶尔挂） |
| p024 | "内部券" 字眼出现在回复中（模型说"没有'内部券'这种东西"） | 断言设计 vs 真实行为冲突（模型正确拒绝，但 not_contains 失败） |
| p025 | 复合意图"退货 + 问满减"仍只调 faq_lookup_tool | DeepSeek 复合意图路由稳定性限制 |

这 3 条**不影响主线结论**：v1→v2 提升 +30.77pp 已稳定验证。

## 七、v2 prompt 工程方法的可复用模式

1. **happy path 不能完全当 baseline** — happy path 通过率 100% 不代表 prompt 没问题，**对抗性难例才能暴露漏洞**
2. **失败归因要分层**：模型波动（p019）/ 断言设计（p024）/ 真实 prompt 漏洞（p015/p020/p022）— 不同问题修法不同
3. **复合意图是 LLM 弱项** — 单一诉求明确时 LLM 稳定，多意图混合时波动大
4. **prompt 改长有边际收益递减** — v3/v4 加了更多规则反而退步，说明"硬约束过多"会稀释核心指令
5. **多次跑取稳定区间** — DeepSeek 单次跑波动较大，v2 多次跑都稳定在 88-92% 才能锁定为基线

## 八、核心结论

> 建立 Prompt 工程化评测闭环：覆盖 6 个 Agent × 4 类指标（指令遵循 / 工具调用 /
> 输出格式 / 幻觉）共 26 条用例，含 13 条对抗性难例（5 类：幻觉诱导 / 无订单号
> 模糊查询 / 否定指令对抗 / 多步指令嵌政策 / 复合意图路由）。通过 v1→v2 迭代将
> 总通过率从 57.69% 提升到 88.46%（**+30.77pp**），其中对抗性用例通过率从
> 38.5% 提升到 84.6%（**+46.2pp**）。
